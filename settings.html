Backend TRIPA

Les données sont stockées sur le backend TRIPA (Node/Express + SQLite). L'adresse de l'API est http://localhost:3000/api. Pour la changer, définissez window.TRIPA_API_BASE ou modifiez js/api.js.

Rôles & Permissions

Rôles disponibles pour les membres gérés par les administrateurs. Pour créer un rôle personnalisé, rendez-vous dans la section Membres (bouton « Nouveau membre → Créer un rôle »).

Couleur de l'application

Choisissez la couleur principale (accent) de TRIPA. Ce choix est enregistré sur cet appareil et appliqué sur toutes les pages.
